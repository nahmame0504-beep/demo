TP 6 : Spring Boot & Swagger - Documentation d'API Microservices

Ce projet constitue le TP 6 portant sur la mise en place, la configuration et la personnalisation de la documentation d'une API RESTful dans une architecture Microservices en utilisant Spring Boot et Swagger / OpenAPI 3 (via springdoc-openapi).

 Objectifs du TP

Intégrer Swagger / OpenAPI 3 dans une application Spring Boot.

Documenter les points d'entrée (Endpoints) de l'API REST (Operations, Parameters, Responses).

Documenter les modèles de données (DTOs / Entities) à l'aide des annotations OpenAPI (@Schema).

Personnaliser l'interface Swagger UI (titre, description, version, contact, licence).

Tester dynamiquement les endpoints de l'API via l'interface interactive Swagger UI.

🛠️ Technologies Utilisées

Java : 17 ou supérieur

Spring Boot : 3.x

Spring Data JPA & H2 Database (ou MySQL)

Springdoc OpenAPI UI : springdoc-openapi-starter-webmvc-ui (v2.x)

Maven : Gestionnaire de dépendances

Lombok : Pour réduire le code boilerplate (Getters/Setters, Constructors)
